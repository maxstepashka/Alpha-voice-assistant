# Голосовой ассистент «Альфа»
## Описание
Альфа - голосовой ассистент, предназначенный для комплексной автоматизации действий на персональных компьютерах.

Программа оборудована набором встроенных комманд и функционалом создания пользовательских сценариев с использованием графического интерфейса.

## Функции
* Управление  **веб-браузерами**
* Взаимодействие с **операционными системами Windows 10/11**
* Работа с **системами поиска информации, музыки и видео**
* Голосовой ввод текста
* Управление программами на устройстве
* Взаимодействие с системой через **команды CMD и Python** (**Для продвинутых пользователей**)
> [!NOTE]  
> Программа поддерживает объединение нескольких действий в сценарии, что позволяет настраивать ассистента для выполнения комплексных задач.

## Установка
Для установки перейдите по следующей ссылке: https://github.com/maxstepashka/Alpha-voice-assistant/tags

Выберите версию и нажмите на нее. **Актуальная версия на текущий момент: v5.0.1**

На странице версии выберите файл-установщик `alpha_voice_assistant.exe` и скачайте его.\
Запустите установщик и установите Альфу как обычную программу для **Windows 10/11**.

После установки в меню `Пуск` появится папка `Alpha voice asssistant` c приложением.\
Запустите приложение и нажмите на вкладку "Справка" на боковой панели для получения инструкции по использованию.
