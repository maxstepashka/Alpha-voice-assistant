# Инструкция по сборке из исходного кода
>[!WARNING]
>На данный момент Альфа поддерживает **операционные системы Windows 10/11**.
>Комплектация репозитория не даeт возможности сборки на других операционных системах.
>
>При желании, пользователь имеет возможность доработать код для запуска на платформах вне **Windows**.
## Зависимости
* Flutter 3.41
* Python 3.13
* Pyinstaller 6.15

>[!NOTE]
>Возможно использование более новых версий, не нарушающих обратную совместимость.

## Шаги сборки
Скачайте или склонируйте репозиторий на свой компьютер

Создайте директорию `building`.\
В созданную папку поместите директории `core`, `config` и `app` из репозитория.

В директории `building` также создайте директорию `alpha`, куда будут помещены результаты сборки.

## Сборка приложения

>[!IMPORTANT]
>Для сборки приложения на Flutter могут потребоваться дополнительные компоненты Visual Studio для разработки приложений на C++.
>
>Запустите команду `flutter doctor` для показа отсутствующих зависимостей.

Перейдите в директорию `building\app` и выполните команду:

```
flutter build windows --release
```

После сборки приложения результаты станут доступны в директоиии `building\app\build\windows\x64\runner\Release`\
Переместите их в директорию `building\alpha`

## Сборка ядра
Перейдите в директорию `building\core` и выполните команду:

```
pyinstaller alpha_core.spec
```

По окончании сборки ядра результаты станут доступны в директории `building\core\dist\alpha_core`\
Переместите их в директорию `building\alpha`

## Добавление компонентов
Переместите директории
```
building\config
building\core\vosk-model-small-ru-0.4
building\core\vosk-model-small-ru-0.22
```

в директорию `building\alpha`

Процесс сборки приложения завершён.

## Устранение неисправностей
Если в процессе сборки возникла ошибка, проверьте установку зависимостей.
>[!TIP]
>Если собранное ядро не запускается, рекомендуется вызвать его в консоли.\
>Это позволит увидеть сообщение об ошибке без закрытия окна.
