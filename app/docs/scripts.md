# **Пользовательские сценарии**

**Сценарий** - последовательность команд, которые ассистент выполнит, услышав ключевую фразу сценария.

Для перехода к сценариям откройте интерфейс и нажмите «**Сценарии**».

# **Структура**

Во вкладке «**Сценарии**» находится поле поиска, кнопки добавления, сохранения и загрузки сценариев, а также блоки, отображающие сами сценарии.

Каждый блок содержит **название** сценария, ключевую фразу и список действий для выполнения.

# **Добавление**
Для добавления сценария нажмите на кнопку «**Добавить**».

Введите название и ключевую фразу. Вы можете перечислить ключевые фразы через **запятую**.

После этого добавьте необходимые действия. Выберите действие и параметр, если поле для него доступно.

При нехватке полей воспользуйтесь кнопкой «**Добавить поле**». Вы также можете удалять поля.

По завершении нажмите кнопку «**Сохранить**»

## **Редактирование**
Процесс редактирования существующего сценария аналогичен добавлению.

Возможно изменять лишь действия.

Название и ключевая фраза закреплены за сценарием.

## **Удаление**
Удалять существующие сценарии можно из вкладки «**Сценарии**».

После удаления восстановить сценарий можно только **повторным добавлением**.

## **Экспорт и загрузка**
Альфа поддерживает экспорт всех сценариев и их ключевых фраз в отдельный файл.\
При загрузке этого файла в редактор сценариев на другом устройстве они автоматически перенесутся.

Для экспорта сценариев нажмите кнопку «**Сохранить в файл**» во вкладке «**Сценарии**».\
В появившемся окне выберите файл, в который будут сохранены сценарии.

Для загрузки сценариев нажмите кнопку «**Загрузить сценарии из файла**» во вкладке «**Сценарии**».\
В появившемся окне выберите файл, из которого будут загружены сценарии.

Файлы сценариев часто хранятся с расширениями «**.txt**» или «**.adsf**» (Alpha Data Storage Format)

**Не рекомендуется** редактировать файлы со сценариями вручную.\
Это может привести к ошибкам, из-за которых загрузчик не сможет считать файл.
