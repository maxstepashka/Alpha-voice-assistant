# **Голосовой ассистент «Альфа»**
# **О программе**

Альфа представляет собой голосового ассистента с графическим интерфейсом.\
Альфа имеет как набор заранее предустановленных команд, так и возможность добавлять собственные.

Программа способна взаимодействовать с операционными системами **Windows 10/11**. Кроме того, ассистент способен управлять большинством известных браузеров.\
На данный момент проводится работа по интеграции с другими программами.

Подробнее о средствах управления программами и взаимодействия будет рассказано позже.

# **Как запустить ассистента**
Для запуска откройте интерфейс приложения и нажмите кнопку «Запустить» на боковой панели.

Откроется новое окно. Дождитесь появления надписи «**Голосовой ассистент готов к использованию**».

После появления этой надписи становится возможным исполнение голосовых команд. Подробнее о них будет рассказано позже.

Для отключения ассистента скажите «**Альфа, заверши работу**» или «**Альфа, выключись**».

# **Интерфейс приложения**
Интерфейс приложения позволяет легко редактировать настройки и возможности ассистента.

Основной интерфейс состоит из трех вкладок:
- **Главная**
- **Настройки**
- **Сценарии** - окно для редактирования навыков и команд ассистента.
О том, как настраивать ассистента и редактировать сценарии, будет рассказано позже.
