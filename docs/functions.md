# **Функции**
## **Возможности приложения**

**Команды с параметрами**
- Открыть сайт или приложение
- Выполнить команду CMD и Python (Для продвинутых пользователей)

**Поиск**
- Поиск информации в браузере
- Поиск видео
- Поиск музыки

**Управление браузером**
- Открыть новую вкладку
- Открыть предыдущую вкладку
- Открыть следующую вкладку
- Открыть режим инкогнито
- Пролистать вверх
- Пролистать вниз
- Пролистать в начало страницы
- Пролистать в конец

**Управление ОС**
- Свернуть окно
- Развернуть окно
- Закрыть окно
- Сменить раскладку клавиатуры
- Открытие встроенных приложений
- Ввести сказанный текст

# **Указания к командам**
## **Управление браузером**
Для выполнения команд управления браузером он должен быть открыт. Кроме того, необходимо, чтобы фокус находился именно на окне браузера.

## **Ввод текста голосом**
Для того чтобы ввести текст голосом, используйте команду "напиши" или "введи", затем скажите, что нужно написать.

Для ввода знаков пунктуации скажите название знака.

**Пример**: Альфа, напиши «Это тестовая фраза **запятая** проверяем работу функции **точка**».

# **Примеры команд**
**Активационная фраза** - фраза, по которой вызывается ассистент. По умолчанию это «**Альфа**». Её можно изменить в настройках.
- Альфа, открой карты.
- Альфа, открой предыдущую вкладку.
- Альфа, смени язык.
- Альфа, включи песню "Лесник".
- Альфа, найди видео про геометрию.
